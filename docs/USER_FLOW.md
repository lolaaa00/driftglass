# Reviewer path

1. Connect an injected wallet and switch to Studionet `61999`.
2. Open **Compose**, enter the subject, canonical domain, official HTTPS sources, precise reliance clauses, interval, and note.
3. Create the draft and wait for finalized majority agreement, successful execution, and the contract reread.
4. Open the record and activate the baseline in a separate consensus transaction.
5. Inspect verified excerpts and source commitments.
6. Open **Checkpoint** from an active record. Any connected account may initiate an eligible semantic check.
7. Confirm the reread shows a new sequence, clause verdicts, requester, timestamp, and aggregate assessment.

Failed consensus, execution failure, rejected signatures, missing sources, and inconclusive evidence remain explicit and never display as successful state changes.
